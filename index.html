う-verbs

ない — negative

Change the final う sound to its あ sound + ない.

かく → かかない

ChangeExample
～う → わかう → かわない
～く → かかく → かかない
～ぐ → がおよぐ → およがない
～す → さはなす → はなさない
～つ → たまつ → またない
～む → まのむ → のまない
～る → らとる → とらない

た — short past

The change depends on the verb's final ending.

のむ → のんだ

EndingExample
う・つ・る → ったかう → かった
む・ぶ・ぬ → んだのむ → のんだ
く → いたかく → かいた
ぐ → いだおよぐ → およいだ
す → したはなす → はなした

Exception: いく → いった

なかった — negative past

Make the ない form, then change ない → なかった. The same う → あ sound change applies.

かく → かかない → かかなかった

ChangeExample
～う → わかう → かわなかった
～く → かかく → かかなかった
～ぐ → がおよぐ → およがなかった
～す → さはなす → はなさなかった
～つ → たまつ → またなかった
～む → まのむ → のまなかった
～る → らとる → とらなかった

て — て-form

The change depends on the verb's final ending.

およぐ → およいで

EndingExample
う・つ・る → ってかう → かって
む・ぶ・ぬ → んでのむ → のんで
く → いてかく → かいて
ぐ → いでおよぐ → およいで
す → してはなす → はなして

Exception: いく → いって

たり — listing actions

Make the た form + り. It uses the same ending groups as た.

のむ → のんだ → のんだり

EndingExample
う・つ・る → ったりかう → かったり
む・ぶ・ぬ → んだりのむ → のんだり
く → いたりかく → かいたり
ぐ → いだりおよぐ → およいだり
す → したりはなす → はなしたり

Exception: いく → いったり

る-verbs

Drop る, then add the new ending.

Using たべる:

Formたべる
ないたべない
たたべた
なかったたべなかった
てたべて
たりたべたり

Watch out: not every verb ending in る is a る-verb.

かえる → かえらない
はいる → はいらない

These are う-verbs.
